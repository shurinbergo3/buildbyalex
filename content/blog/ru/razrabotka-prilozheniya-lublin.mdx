## Что делаю

Работаю в React Native - один исходный код, нативная производительность, публикация сразу в App Store и Google Play. Типичные проекты для бизнеса из Люблина:

- **Клиентское приложение** - запись, заказы, программа лояльности, push-уведомления
- **Внутренний инструмент** - приложение для выездных сотрудников, сканирование штрихкодов, отчеты
- **MVP стартапа** - ключевые функции, готовые к тестированию с реальными пользователями
- **Интеграция с существующей системой** - мобильное приложение, подключенное к CRM, ERP или магазину

Каждый проект начинается с обсуждения: что пользователь должен сделать в приложении шаг за шагом. Потом - оценка и фиксированная цена.

## Как проходит работа

1. **Созвон** - 30-60 минут в Zoom. Рассказываете о бизнесе и о том, что приложение должно делать.
2. **Фиксированная цена** - получаете документ с объемом работ и одной цифрой. Без диапазонов.
3. **Проектирование** - сначала макеты в Figma, чтобы видели приложение до написания кода.
4. **Разработка** - еженедельные спринты с рабочей версией на TestFlight/Play Console.
5. **Запуск** - публикация в App Store и Google Play, передача кода и документации.

Оплата поэтапно: 30% до старта, остаток - по контрольным точкам. Предоплату 100% не беру.

## FAQ

**Сколько стоит мобильное приложение для бизнеса в Люблине?**
Простое приложение с готовым бэкендом (Firebase, Supabase) - от 3000 €. Проект с собственным API, бизнес-логикой и интеграциями с внешними системами - от 6000 до 9000 €. Цена зависит от количества экранов, сложности бэкенда и нужных интеграций. Всегда даю фиксированную сумму, не почасовую оплату.

**Сколько времени занимает разработка мобильного приложения?**
Простой MVP с 6-8 экранами - 6-8 недель. Приложение с собственным бэкендом, платежами и push-уведомлениями - 12-16 недель. Главная переменная - объем серверной части и количество интеграций с внешними API.

**Разрабатываете ли вы под iOS и Android одновременно?**
Да. React Native дает одно приложение, которое нативно работает на обеих платформах. Отдельный код под iOS и Android не пишу - это снижает стоимость и сроки без ущерба для интерфейса и производительности.

**Можно ли подключить приложение к существующему сайту или магазину?**
Да. Подключаю мобильные приложения к существующим системам через API: WooCommerce, Shopify, собственная CMS, CRM, ERP. Если в вашей системе есть REST API или webhooks - интеграция входит в стандартный объем проекта.

**Что происходит после публикации приложения?**
Вы получаете аккаунты App Store и Google Play, полный исходный код и документацию по API. Можно также договориться о сопровождении по подписке - обновления, новые функции, техническая поддержка.

**Будет ли приложение работать без интернета?**
Если это нужно - да. Реализую офлайн-режим с локальной базой данных (SQLite, AsyncStorage) и синхронизацией при восстановлении соединения. Стандартное решение для полевых сотрудников или любых сценариев с нестабильным интернетом.
