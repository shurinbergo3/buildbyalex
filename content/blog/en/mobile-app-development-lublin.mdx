## How the work goes

1. **Intro call** - 30-60 minutes on Zoom. You describe the business and what the app needs to do.
2. **Fixed quote** - I send a scope document with a single number. No range, no "it depends."
3. **Design** - wireframes and UI in Figma first, so you see the app before a line of code is written.
4. **Build** - weekly sprints with a working build on TestFlight/Play Console each time.
5. **Launch** - App Store and Google Play submission, code handover, documentation.

Payment in stages: 30% upfront after the contract is signed, the rest tied to milestones. I don't ask for 100% in advance.

## FAQ

**How much does a mobile app cost for a business in Lublin?**
A simple app using a ready-made backend (Firebase, Supabase) starts from €3,000. A project with a custom API, business logic, and third-party integrations runs from €6,000 to €9,000. The price depends on the number of screens, backend complexity, and required integrations. I always give a fixed price - no hourly billing.

**How long does it take to build a mobile app?**
A lean MVP with 6-8 screens takes 6-8 weeks. A more complete app with a custom backend, in-app payments, and push notifications takes 12-16 weeks. The main variable is backend scope and the number of external API integrations.

**Do you build for iOS and Android at the same time?**
Yes. React Native produces one app that runs natively on both platforms. I don't write separate codebases for iOS and Android - that means lower cost and a shorter timeline without sacrificing UI quality or performance.

**Can the app connect to my existing website or store?**
Yes. I integrate mobile apps with existing systems via API: WooCommerce, Shopify, custom CMS, CRM, ERP. If your system exposes a REST API or webhooks, integration is a standard part of the project.

**What happens after the app is published?**
You receive full ownership of the App Store and Google Play accounts, the complete source code, and API documentation. I also offer ongoing maintenance on a retainer - updates, new features, technical support. We agree on terms at the contract stage.

**Will the app work offline?**
If you need it to, yes. I implement offline mode with a local database (SQLite, AsyncStorage) and sync when the connection is restored. This is standard for field staff apps or any use case where connectivity isn't guaranteed.

**How does payment work?**
30% before work starts (after signing the contract and approving the wireframes), remaining payments tied to delivery milestones. I invoice in EUR and accept SEPA bank transfers. No 100% upfront.
