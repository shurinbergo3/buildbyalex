## What I build

An **AI agent** is not a decision tree that captures a name and stops. It connects to your systems and takes actions. A customer types "where is my order" - the agent checks your system and replies with real data, instead of pointing them to a FAQ page.

Depending on what you need, I build:

- an FAQ chatbot on your website or WhatsApp with a CMS panel, so you edit answers without a developer,
- an agent with CRM integration that qualifies leads and writes records to HubSpot or Pipedrive automatically,
- a customer support agent with human escalation - complex cases go to your team with the full conversation history attached,
- a multi-agent system with separate agents for lead qualification and customer support, each with its own knowledge base.

Every build includes an admin panel: full conversation history, data export, and a knowledge base editor. You own the code - after the project you can work with any developer.

**What's the difference between an AI agent and a chatbot?**
A chatbot answers questions from a knowledge base and responds to a prompt. An AI agent takes actions: pulls data from an external system, writes leads to CRM, sends emails, creates support tickets. It works in multiple steps and makes decisions based on defined rules.

**How long does an AI agent implementation take?**
An FAQ chatbot: 2 weeks. An AI agent with CRM integration: 3-4 weeks. A multi-agent system: 6-8 weeks. After the first week of work you have a working prototype on a test environment - you don't wait until the end of the project for a first demo.

**Which systems can the AI agent integrate with?**
I most often integrate with HubSpot, Pipedrive, WooCommerce, and Baselinker. If your system has an API or webhook - we can connect. For systems without an API I build the integration through n8n or Make.

**Can the AI agent serve customers overnight and on weekends?**
Yes - that's one of the main reasons to deploy one. The agent replies in 2-3 seconds around the clock. Complex cases escalate to a human with the full conversation history, so the customer doesn't have to repeat themselves.

**When does the investment in an AI agent pay off?**

If a team member spends 3 hours a day on repetitive answers, the agent takes that work over at a fraction of the cost.
